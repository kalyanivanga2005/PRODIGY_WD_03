# 🎮 Tic-Tac-Toe Web Application

A fun and interactive **Tic-Tac-Toe Web Application** built using **HTML, CSS, and JavaScript**. The game allows two players to play Tic-Tac-Toe interactively while automatically detecting winning combinations and draw situations.

## ✨ Features

- ❌ Player X and ⭕ Player O gameplay
- 🎯 Interactive game board
- 🔄 Automatic player turn switching
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🎉 Winner celebration
- 🔁 Restart / New Game functionality
- ✨ Interactive hover and click effects
- 📱 Responsive design for different screen sizes
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Game logic, player turns, winner detection, and restart functionality
