## 🎮 How to Play

1. Select the desired game mode.
2. Player X starts the game.
3. Click an empty cell to place your symbol.
4. Players take turns placing X and O.
5. Get three matching symbols in a row to win.
6. The game automatically detects a winner or draw.
7. Use **New Game** to start another round.
8. Use the **Mute/Unmute** button to control game sounds.

## 🏆 Winning Conditions

A player wins by placing three matching symbols:

* Horizontally
* Vertically
* Diagonally

Example:

```text
X | X | X
---------
O | O |
---------
  |   |
```

## 📊 Scoreboard

The game keeps track of:

* ❌ X Wins
* ⭕ O Wins
* 🤝 Draws

The scoreboard is updated automatically after each completed game.

## 🤖 Computer Mode

The application also includes a **Player vs Computer** mode where the computer responds to the player's moves and attempts to make strategic moves during gameplay.
